Basics & Operators Module 01

Variables, Dynamic Typing & Mathematical Operators

Python dynamically infers variable types without explicit declarations. Mathematical operations enforce strict rules regarding floating-point precision and floor division rounding toward negative infinity.

# Floor division rounds down toward negative infinity

print(10 / 5) # 2.0 (float)

print(10 // 3) # 3 (rounds down)

print(-10 // 3) # -4 (rounds DOWN from -3.33)

print(10 % 3) # 1 (remainder)

Exam Trap: int("Hello") raises a ValueError
I/O & Formatting Module 02

Input Processing & f-String Precision Formatting

The input() function always yields a string (str). Numerical operations require explicit type casting. Modern Python utilizes f-strings with precision specifiers.

acc = 0.9478

samples = 1256789

print(f"{acc:.2%}") # "94.78%"

print(f"{samples:,}") # "1,256,789"

Tip: Arithmetic on raw input() causes a TypeError
Strings & Methods Module 03

String Immutability & Slicing Syntax

Strings are immutable sequences. Methods like .strip() and .lower() return NEW strings and do NOT modify variables in place unless explicitly reassigned.

s = "Artificial"

sub = s[1:8:2] # Start=1, Stop=8 (excl), Step=2

print(sub) # Output: "riii"

# Methods return new strings:

text = " Python "

text.strip() # 'text' remains " Python "!

Exam Trap: Unassigned string method calls do not alter the source variable!
Control Flow Module 04

Control Flow & Structural Pattern Matching (`match/case`)

Python 3.10+ provides structural pattern matching. Features include sequence unpacking, conditional guards (if), OR patterns (|), and the wildcard (_).

point = (0, 5)

match point:

  case (x, y) if x == y: print("Diagonal")

  case (0, y): print(f"Y-axis: {y}") # MATCHES!

  case _: print("Other")

Data Structures Module 05

Lists vs. Tuples: Mutability & Methods

Lists ([ ]) are mutable sequences; Tuples (( )) are immutable. In-place mutator methods modify objects and return None.

my_list = [1, 2]

my_list.extend((3, 4)) # [1, 2, 3, 4]

my_list.append([5, 6]) # [1, 2, 3, 4, [5, 6]]

print(len(my_list)) # 5 elements total!

extend unpacks elements; append inserts the collection intact
Data Structures Module 06

Memory Allocation: Aliasing vs. Shallow Copying

Direct variable assignment creates an alias (shared memory pointer). Calling .copy() creates a shallow copy—outer list containers are duplicated, but inner nested elements retain original memory pointers!

original = [[1, 2], [3, 4]]

shallow = original.copy()

shallow[0][0] = 99

print(original[0][0]) # Output: 99 (Shared inner sublist!)

Solution: Use copy.deepcopy() for full nested independence
