Basics & Operators Module 01

Variables, Dynamic Typing & Division Rules

Python dynamically infers variable types without explicit declarations. Variables act as reference labels pointing to objects in heap memory.

  • Dynamic Typing: x = 10 (x is int). x = "AI" (x is now str).
  • True Division (/): Always returns a float. Example: 10 / 5 = 2.0.
  • Floor Division (//): Rounds down towards negative infinity. Example: 10 // 3 = 3, but -10 // 3 = -4.
  • Modulo (%): Returns remainder. Calculated as a - (b * (a // b)). Example: -10 % 3 = 2.
  • Exponentiation (**): Power operator. Example: 2 ** 3 = 8.

# Explicit Casting Examples

a = int("100") # 100 (int)

b = float(5) # 5.0 (float)

c = bool([]) # False (empty list is falsy)

d = bool([0]) # True (non-empty list is truthy)

Exam Trap: int("Hello") raises a ValueError at runtime!
I/O & Formatting Module 02

Input Processing & Precision f-Strings

The input() function always captures user input as a str. Perform arithmetic only after explicit casting.

  • print(*args, sep=' ', end='\n'): sep defines item separators; end sets trailing character.
  • f-String Format Specifiers: Enclosed inside {value:specifier}.
  • .2f -> Rounds floating point to 2 decimal places.
  • .2% -> Multiplies by 100 and formats as percentage.
  • :, -> Adds comma thousands separators.

acc = 0.947812

count = 1256789

print(f"Acc: {acc:.2%}") # "Acc: 94.78%"

print(f"Total: {count:,}") # "Total: 1,256,789"

print("A", "B", sep="-") # "A-B"

Strings & Methods Module 03

String Immutability & Slicing Syntax

Strings are immutable sequences in Python. Methods NEVER alter original variables; they return entirely new strings.

  • Slicing Syntax: str[start:stop:step]. stop index is non-inclusive!
  • Negative Step Slicing: s[::-1] reverses the string.
  • Method Chaining: Methods can be chained e.g. s.strip().lower().

s = " Artificial "

s.strip() # 's' is STILL " Artificial "!

s = s.strip().lower() # Explicit reassignment needed -> "artificial"

sub = s[0:5:2] # "atf" (indices 0, 2, 4)

Control Flow Module 04

Control Flow & Match/Case Pattern Matching

Python 3.10+ introduced structural pattern matching via match / case.

  • Empty Statements: Empty blocks require pass or ... (Ellipsis) to avoid IndentationError.
  • Wildcard Pattern (case _:): Default catch-all branch.
  • Conditional Guards: case (x, y) if x == y: adds Boolean validation.
  • OR Patterns: case 1 | 2 | 3: matches multiple options.

point = (0, 5)

match point:

  case (x, y) if x == y: print("Diagonal")

  case (0, y): print(f"Y-axis: {y}") # MATCHES!

  case _: print("Other")

Data Structures Module 05

Lists vs. Tuples: Mutability & Methods

Lists ([ ]) are mutable; Tuples (( )) are immutable.

  • In-Place Mutators: Methods like .sort(), .reverse(), and .append() alter list objects directly and return None.
  • .append(x) vs .extend(iter): append adds item intact; extend unpacks elements.
  • Tuple Packing/Unpacking: Single-element tuples require a comma: t = (5,).

lst = [1, 2]

lst.extend((3, 4)) # [1, 2, 3, 4]

lst.append([5, 6]) # [1, 2, 3, 4, [5, 6]] -> len = 5

res = lst.sort() # 'res' is None! 'lst' is sorted in-place.

Data Structures Module 06

Memory Allocation: Aliasing vs. Shallow/Deep Copying

Understanding RAM reference allocation is crucial for exam questions on nested mutable structures.

  • Aliasing (b = a): Both variables point to exact same memory address (id(a) == id(b)).
  • Shallow Copy (b = a.copy()): Outer container is cloned, but inner nested elements still share memory pointers!
  • Deep Copy (b = copy.deepcopy(a)): Full recursive clone. Outer and inner elements are completely independent.

original = [[1, 2], [3, 4]]

shallow = original.copy()

shallow[0][0] = 99

print(original[0][0]) # Output: 99 (Nested list shared reference!)
